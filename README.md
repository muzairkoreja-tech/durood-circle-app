# Durood Circle — Android app

Read Durood-e-Pak every day and join group campaigns with family and friends.

**Download:** https://durood-circle-api.onrender.com/download

This repository only hosts the Android installer (APK) on its [Releases](../../releases) page.
After installing, the app keeps itself up to date automatically.

Installing: open the downloaded `DuroodCircle.apk` and allow "Install from this source" when Android asks.
